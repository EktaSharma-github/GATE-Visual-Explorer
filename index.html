Node = GATE test paper

Arrow A → B = B is allowed as a secondary paper when A is selected as the primary paper.

Larger node = more available secondary-paper options.

Quick Analysis

The most connected papers are especially useful for candidates considering a second paper because they offer more permitted choices.
Remember that the combination table only tells you whether a pairing is permitted. It does not indicate difficulty, syllabus overlap, admission probability, rank prediction or score prediction.
